01 / EXECUTION PATH

从“能不能做”到“实际发生了什么”

一条工具请求按阶段留下证据。缺少证据时，状态保持未知。

保持地图开放

理论上可能，不代表已实现

Android API、系统组件、设备硬件和授权桥提供候选路径。AndroBody 保留这些可能性，再逐项核对可行条件。

THEORETICAL ≠ AVAILABLE
理论候选设备 / 权限 / 目标调用与回执观察与未知

02 / NATIVE CAPABILITIES

设备能力，有边界地接入

当前工具按 Android 权限、应用身份和真实回执运行。

01 / SENSE

感知

电池、网络、有界传感器采样、获准后的通知读取与本机录音。

权限与边界

麦克风、通知访问分别由 Android 控制；通知和音频正文不会自动写入普通运行日志，也不会自动发送给模型。

02 / ACT

行动

TTS、本机通知发布、私有文本工作区 CRUD 与本机网关工具。

执行状态

系统收到派发、目标应用接受、工具回执和独立读回是不同阶段；提交不等于业务完成，取消也不等于回滚。

03 / PROOF

回执与恢复

每个动作关联请求、工具回执、运行追踪和本机会话检查点。

失败也能接管

未知结果不会自动重放。用户可以沿同一请求身份查看记录、复制依据并继续只读核对。

03 / A DEVELOPING BODY

身份稳定，器官逐步生长

应用是权限与执行边界；设备提供可探索的 API、传感器、麦克风和系统服务。能力不是凭名称宣称，而是通过适配、授权、尝试与结果逐项建立。

这是 AndroBody 的设计方向，不是“所有能力已就绪”的承诺。

04 / VERIFIED SCOPE

已验证范围，逐项公开

模拟器、平板、真实模型与人工体验分别报告。

PASS · BUILD + JVM

v0.6.9 双身份候选

AndroBody 目标包与旧包迁移源各 92 项 JVM 测试、Verification lint 通过；主 APK 与 AndroidTest APK 均已构建。Android instrumentation 本轮未运行。

PASS · TABLET DATA MIGRATION

本机重加密与读回

Xiaomi 平板迁移后，新旧包各保留 3 份加密会话；新包运行台报告 sessionCount=3。旧包仍保留供回退，Android 系统权限需在新包重新授权。

NOT RUN

模型、权限与人工体验

本轮未调用真实模型或产生计费。新包通知访问、麦克风、悬浮窗等权限尚未重授；ARM64 runtime、真实通知读取、录音听感和人工视觉体验仍未测。

0.6.9 是内部 verification 候选，使用 Android debug 签名。当前没有公开稳定 APK 或公开源代码授权。
