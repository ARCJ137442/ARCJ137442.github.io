# ARCJ137442.github.io

Personal project portal and static project pages, deployed to GitHub Pages.

## Public entry points

- [AndroBody — 安卓之身](https://arcj137442.github.io/AndroBody/): Android native capabilities and verification scope.
- [缀形](https://arcj137442.github.io/zhuixing/): Chinese character structure editor.

The repository root is deployed as-is by `.github/workflows/pages.yml`. Project pages live in their own subdirectories; do not replace or remove unrelated projects when updating the portal.

## Local preview

Run a static server from the repository root, then open `/` and `/AndroBody/` in a browser. No build step or third-party runtime dependency is required.
