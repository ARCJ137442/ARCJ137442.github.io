## 三、网站的意图：它要做什么、不做什么、不仅仅是什么

### 3.0 为什么还没动：真实感

网站不仅仅是展示各种作品，还是要展示**制作作品的人**——那些不能被 Agent 代替的地方。

Agent 可以批量生成产品、写代码、甚至写博客。但 Agent 不能：
- 写出「十四年前，从朋友那儿弄到一个叫 ES文件浏览器 的东西」这样的起源故事
- 写出「像建设新中国一样建设自己」这样的自我反思
- 写出「配了几年的环境，随手搓出的理论」这样的真实感悟
- 写出「人好像一下子变牛逼了，过一阵子又打回原形了」这样的诚实

**这才是没有立马重构网站的原因**——不是因为没有能力，而是因为还没想清楚「真实感」要怎么呈现。一个精心设计但没有灵魂的网站，不如一个粗糙但真实的「测试页面」。

life-series 里的随笔（011-043）才是这个网站应该有的灵魂：

**创造者的哲学**
- 「体验与创造」—— 「你不去想，就不会出现」「使用一款软件，是因为它出自你自己之手？」
- 「编程？」—— 从 Minecraft JS 模组到现在的完整起源故事——「不如我自己来！」
- 「创意友好的Agent时代」—— Agent 让「想不到」的含金量更高

**自我建设的方法论**
- 「自我的中央报」—— 「生活日志，就是个人的中央报刊」「记录的过程是主要的，内容的质量是次要的」
- 「意图-现状=问题」—— 一个思维框架：弄清意图 → 认识现状 → 定义问题 → 行动
- 「写作5分钟，框架2小时」—— 「先做，然后观念开始转变，转变的新观念再产生新的做法」

**Agent 时代的人之本体**
- 「配了几年的环境，随手搓出的理论」—— 「人好像一下子变牛逼了，过一阵子又打回原形了——而这，是我们想要的吗？」
- 「允许自己停下来」—— 「在外部工具消失后，剩下的人自己，自我内核，动机意志，这些同样会闪烁光芒。工具是水涨船高的水，而非船本身」
- 「渴望凝固的时空」—— 「曾经手敲的游戏依然可以打开，而如今的自己已经没了那种简单的快乐」

**网站的核心不是项目，是人。项目是人的证据，不是人的替代品。**

而「真实感」的哲学根基，在 life-series 042 里写得很清楚：

> 在「创造」的逻辑中，不会有立马能端到自己面前的东西，也未曾有过在社会分配中叫「不劳而获」的道理。你不去想，就不会出现。

> 你，要在体验之后留下什么？是世界铭刻给你的一层美妙回忆，还是你撰刻给世界的一笔灵魂印记？使用一款软件，是因为它呈现给你效果很6，还是因为它出自你自己之手？

**这就是为什么网站不应该追求「精美」而应该追求「真实」**——因为这个人的核心身份是「创造者」而非「体验者」。一个自己手搓的粗糙但真实的页面，比一个 AI 生成的精美但空洞的页面，更符合这个人的灵魂。

### 3.1 它要做什么

**回答「ARCJ137442 是怎样一个人？」——而不是「ARCJ137442 会什么语言」。**

你的真实画像是：

> 一个**阶段性深度投入**的探索者——从 Flash 游戏到认知推理系统到 AI Agent 基础设施，每个阶段都做到了「能跑起来」的程度，然后转向下一个让他兴奋的问题。

但更深层的是：

> 一个**正在构建生命操作系统的人**——从理论（ACA、CCC）到系统（ExoMind）到应用（法律推理、语音 IME）到个人生活（life-series、ob-notes），你在用代码探索「智能机器如何思考和工作」这个问题。

### 3.2 它不是什么

- ❌ **不是简历/CV** —— 不是求职导向的技能清单
- ❌ **不是项目列表** —— 不是 69 个仓库的索引
- ❌ **不是技术博客** —— 不是教程和文章的集合
- ❌ **不是产品官网** —— 不是 ExoMind 的营销页
- ❌ **不是「测试页面」** —— 不是实验的垃圾场

### 3.3 它不仅仅是什么

- ✅ **是思考的外化** —— 你在 life-series 里持续思考，网站是那些思考的公开投影
- ✅ **是探索的记录** —— 每个阶段的工作都是对同一个问题的不同角度探索
- ✅ **是灵魂的投影** —— 不是展示「我做了什么」，而是展示「我在追问什么」
- ✅ **是连接的接口** —— 让 NARS 社区、Agent 开发者、同频的人能找到你

### 3.4 从「产品对齐」到「灵魂对齐」

| 维度 | 旧模式（CV/产品对齐） | 新模式（灵魂对齐） |
|---|---|---|
| **核心问题** | 我会什么？ | 我在追问什么？ |
| **组织方式** | 按项目/语言分类 | 按问题/兴趣域组织 |
| **时间感** | 最新项目在前 | 问题的演进历程 |
| **访客感受** | 「这个人挺厉害」 | 「这个人有意思」 |
| **更新动力** | 有新项目才更新 | 有新想法就更新 |
| **与 life-series 的关系** | 无关 | 网站是 life-series 的公开投影 |

### 6.1 推荐路线：「数字花园 + 交互体验」混合法

结合你的实际情况，推荐以下混合方案：

**首页**：一句哲学内核 + 交互式 Narsese 演示

> 「如何让机器像人一样从经验中推理？」
>
> 我是 ARCJ137442，一个用 Rust、Julia、TypeScript 探索非公理推理系统的开发者。
> 这里是我的思考和作品。

**主体**：按「能力域」而非时间线组织

```
├── 推理系统（NARS 生态）—— 理论 + 多语言实现
├── Agent 工具链（当前活跃）—— 工程能力
```

**每个域**标注「活跃 / 冻结 / 历史」状态，让访客一眼看出你当前在做什么、曾经做过什么。

### 6.2 叙事结构

采用「双身份并置」+「问题驱动」的混合叙事：
